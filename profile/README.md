#  Common Lisp tools

> Note: The `github` segment in the system and package names is only for namespacing adn a reference to where this project is hosted. This project and the `cl-sdk` organization have no affiliation with, and are not endorsed by, GitHub.

The `cl-sdk` organization provides a shared foundation for Common Lisp development, focused on reusable packages published under the Unlicense. Its projects cover web application tooling, code and domain generation, protocol and data format libraries, and supporting utilities such as CORS, multipart/form-data, environment-variable handling, and input policies. The organization also maintains example applications and documentation resources.
