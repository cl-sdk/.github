#  Common Lisp tools

> Note: The `github` segment in the system and package names is only a reference to where this project is hosted. This project and the `cl-sdk` organization have no affiliation with, and are not endorsed by, GitHub.

The `cl-sdk` organization provides a shared foundation for Common Lisp development, focused on reusable packages published under the Unlicense. Its projects cover web application tooling (`wst`), code and domain generation (`cgt`, `domaindsl`), protocol and data format libraries (`io.github.cl-sdk.json`, `io.github.cl-sdk.xml`, `io.github.cl-sdk.csv`, `io.github.cl-sdk.ini`, `io.github.cl-sdk.openapi`), and supporting utilities such as CORS, multipart/form-data, environment-variable handling, and input policies. The organization also maintains examples and documentation repositories, including `wst-bookmark-example`, `wst-url-shortener-example`, and `cl-sdk.github.io`.
